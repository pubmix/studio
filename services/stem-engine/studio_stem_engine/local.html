Or split an audio file from your computer (MP3 or WAV, up to 100 MiB and 15 minutes).

Your split

Save the four WAVs, then upload them using Studio’s WiFi upload page. Assign vocals, melody, bass and rhythm to tracks 1–4 using the device’s file picker.

Pair the Dub-Box Wi-Fi upload page

On the device upload page, open “Connect the existing Studio stem engine”, enter this companion’s address and paste your pairing key. The companion must be started with --device matching that page’s origin. For a phone, use the computer’s LAN address and start the companion with --host 0.0.0.0.

Keep this key private. It permits access to your companion’s jobs and audio.

Recent splits
