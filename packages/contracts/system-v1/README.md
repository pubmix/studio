# STUDIO system baseline I0.1

Machine-readable compatibility expectations for the [shared architecture](../../../docs/SYSTEM_ARCHITECTURE.md). baseline.json records canonical lanes, native/P1 formats, processor ownership, H0.1 pin reservations and current implementation flags. Run make integration-test at repository root to check it against engine output, firmware constants, transfer validation and pin accounting. This is proposed hardware data, not an enabled driver or netlist. Physical integration and benchmark gates remain in the shared architecture.
