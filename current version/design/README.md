# Studio visual design work

`studio-ui-concepts` contains the Chalk, Graphite and Petal concept images.
`studio-ui-redesign` contains later SVG/PNG studies, effects-editor ideas,
track icons and DAW research. These are design artifacts, not screenshots proving
that every illustrated feature is implemented. Read each folder's README and
research notes for sources, rationale and limitations. Current firmware implements
three themes, enlarged touch targets, a wider piano and page-based sound controls.
Further visual refinement requires device review. No runtime dependencies here.
