# Host layout previews

These six menu and theme-picker images were rendered from copies of the actual screen source using the real FreeSans12 and FreeSansBold18 bitmap glyphs. They are layout checks, not device screenshots. The shared header is intentionally omitted; screen hardware, timing, transport and exact hardware rounded-corner rasterization are not simulated.

All three colorways were visually inspected for label clipping and overlapping controls. Menu and theme picker bodies fit. The accompanying mixer geometry check passed for 17 action rectangles: at least 83×102 pixels, no overlap in each view, all within body y154–608 and clear of the planned header and transport.

PNG files are raster previews; same-name SVG files preserve the glyph runs. Source harness is retained in the workspace under work/studio-ui-host.
